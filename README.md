# ECO-KIN-Game — Legacy/Prototype Support

This repository contains historical/prototype Echohearts: Rebearth game material. It is **not** the current executable runtime source of truth, even when it contains a `.uproject` or `Source/` tree.

## Authoritative repositories

- Canon, systems, story, 125-ID Permanent Dex, production contracts, and publication: `Dlomotion/Echohearts-Rebearth`
- Executable Unreal Engine 5.8 C++ runtime, build/package tooling, CI, tests, and retained runtime evidence: `Dlomotion/ECHOHEARTS-REBEARTH-BUILD-`

Useful prototype code should be audited, corrected, tested, and migrated to the BUILD repository rather than developed here as a parallel runtime.

## Protected Echohearts contracts

- Planet: **Rebearth**
- Creature classification: **Eco-Kin**
- Core attributes: **Vibrance, Density, Harmony, Purity**
- Preserve **Anima-Link** and **Huma-Link** where applicable
- The **125-ID Permanent Eco-Kin Dex** is the roster authority
- Eco-Kin remain autonomous partners
- Avoid derivative franchise terminology or copied proprietary implementations

## Verification boundary

Legacy C++, project descriptors, web files, documentation, or successful static checks in this repository do not establish UE5.8 runtime verification. Use the BUILD repository for clean-clone/LFS, UHT, compile, editor/PIE, Automation, package launch, save/network, performance, and hardware evidence.
